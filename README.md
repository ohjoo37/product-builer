# 마음 캡슐 뽑기 머신 (Mind Capsule Gacha Machine)

하루 한 조각의 따뜻한 응원과 위로를 받을 수 있는 웹 기반 3D 가챠 머신 웹앱입니다.

## 주요 기능
- **3D 가챠 머신 애니메이션**: 투명 돔 안의 28개 캡슐과 레버 조작 및 사운드 효과
- **다크모드 / 화이트모드 테마 지원**: 상단 버튼을 통해 라이트모드와 다크모드를 자유롭게 전환하며, 사용자 설정이 자동 저장됩니다.
- **Web Audio API 사운드**: 가동음, 투하음, 당첨 차임벨 내장
- **풍성한 위로 명언 DB**: 35개 이상의 따뜻한 문구와 일상 실천 프롬프트
- **마음 보관함 (도감)**: 모은 캡슐을 로컬 스토리지에 저장하고 수집률 확인 및 복사 기능
- **캔버스 컨페티**: 캡슐 오픈 시 화려한 축하 효과
