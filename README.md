# 자존감 픽업 머신 (UFO Claw Machine & Self-Esteem Mission Box)

나만의 가치를 건져 올리는 인터랙티브 아케이드 스타일의 웹 기반 크레인 집게 머신 웹앱입니다.

## 주요 기능
- **UFO 크레인 집게 아케이드 애니메이션**: 좌우 이동 조이스틱, 하강/잡기(GRAB) 버튼, 기계식 갈퀴 및 와이어 신축 효과
- **Web Audio API 복고풍 사운드**: 모터 작동음, 집게 클락 소리, 당첨 팡파레 내장
- **자존감 향상 명언 및 미션 DB**: 15가지 이상의 엄선된 명대사, 영화 대사, 시와 함께 실천 가능한 일상 미션 카드 제공
- **수집 보관함 (도감)**: 뽑은 자존감 볼을 로컬 스토리지에 저장하고 수집 현황 확인 및 복사 기능
- **캔버스 컨페티**: 당첨 시 화려한 폭죽 축하 효과
- **🤝 제휴 및 협업 문의 페이지 (`contact.html`)**: Formspree 연동 제휴 문의 폼 및 Disqus 소통 공간 제공
